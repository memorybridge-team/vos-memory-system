CMMT CanonicalState → Target SAM 2 조립 지도

현재 cmmt.canonical_state.v1 export를 소비하는 v1.1 Target 조립 계약과 고정 SAM 2.1 predictor 기준입니다. 핵심 translator와 correction 발생 시의 replay fallback을 분리해 표시합니다. 로컬 injector는 과거 pred_masks/object_score_logits를 제외한 최소 read-state를 조립하며, 실제 checkpoint에서 단일 객체·다객체·late prompt·부재/재등장, 전환 전후 correction과 반복 handoff continuation을 검증했습니다. 진단용 score가 없는 injected history도 같은 최소 계약으로 다시 export할 수 있습니다.

실행 모드

Correction 없음

maskmem_features와 obj_ptr만 전달합니다. Direct Copy·Moment-Matched Copy·Nonlinear Translator는 이 경로를 공유하고 값 처리만 다릅니다. Target이 maskmem_pos_enc를 생성하며, 과거 RGB replay 없이 t+1부터 진행합니다.

전환 이후 correction

현재 RGB와 새 prompt를 Target에 넣습니다. Target이 새 pred_masks, presence score, memory를 만들며 과거 구간 replay는 필요 없습니다.

전환 이전 correction

저장된 RGB와 prompt timeline으로 안전한 기준점부터 Target replay를 수행합니다. 수정 지점 이후의 기존 translated history는 Target-native history로 교체합니다.

연구 단계의 동일 영상 전제

Source와 Target은 같은 영상·frame 순서·switch 시점을 사용한다고 실험 manifest에서 고정합니다. num_frames·video_height·video_width와 영상 hash는 memory handoff payload에 넣지 않습니다. Target runtime은 자신의 영상에서 세 값을 직접 산출하며, 서비스 단계의 영상 식별 검증은 별도 protocol로 둡니다.

읽는 법: 왼쪽 값이 가운데 조립 규칙을 거쳐 오른쪽 필드가 됩니다. 정보 처리 방식과 조립 작업은 배타적인 분류가 아닙니다. 예를 들어 is_conditioning 값은 그대로 보존하면서 cond/non-cond router가 그 값을 읽어 저장 위치를 정합니다. switch_frame 값도 handoff metadata에 그대로 보존하며, controller가 이를 읽어 t+1 시작점을 정합니다. Target inference_state의 영구 필드로 주입하지는 않습니다. Source PE·device·provenance는 검사에는 남지만 Target 실행값으로 주입되지 않습니다.
기록 수와 읽기 수: CanonicalState는 전환 시점까지의 유효 record를 보존합니다. K는 저장 record 축이며 SAM 2의 한 추론 step에서 선택해 읽는 num_maskmem과 같은 뜻이 아닙니다.
장치 정책: 번역·조립된 maskmem_features는 Target storage_device로, obj_ptr와 Target PE는 Target compute/device 정책으로 이동합니다. Source device 문자열을 복사하지 않습니다.
예측 기록: Source pred_masks는 Target inference_state 밖의 화면 검토용 sidecar archive로만 보존하며 Target decoder의 refinement 입력으로 주입하지 않습니다. 과거 Source object_score_logits도 진단 전용입니다. 새 mask와 score는 Target이 새 frame 또는 replay에서 생성합니다.
Correction 정책: 전환 이전 frame을 수정하면 원본 RGB와 prompt timeline을 사용해 안전한 기준점부터 Target replay합니다. pred_masks 번역만으로 수정 이후 history의 일관성을 복원할 수 없습니다.
