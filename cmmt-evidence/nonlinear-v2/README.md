# CMMT nonlinear v2 — system evidence archive

This directory preserves completed, non-runtime evidence moved out of the
`vos-memory-translator-nonlinear` experiment core.

## Provenance

- Source repository: `memorybridge-team/vos-memory-translator-nonlinear`
- Source branch: `task/03-external-zero-shot-protocol-v1-3`
- Source commit: `57b2cd1c2f105b75f12470786f62f1d8105420f1`
- Archived on: 2026-09-28

The source repository retains the compact Task 02 and Task 06 final reports,
their frozen contracts, runtime implementation, and regression tests. This
archive contains the detailed run evidence, historical material, presentation
inputs, and completed workflow audit artifacts that are not required to run
the current Small-to-Base+ translator experiments.

## Contents

- `reports/tasks/02_state_io/runs/`: detailed State I/O inventory evidence
- `reports/tasks/06_runtime/runs/`: detailed injection/runtime gate evidence
- `reports/legacy/`: historical pilot reports excluded from current claims
- `docs/legacy/`: superseded research notes and attribution records
- `docs/presentations/`: mentor-review presentation inputs
- `collaboration/`: migration and completed workflow audit records

Large datasets, checkpoints, paired states, and raw model outputs are not
stored here.
