# Dataset attribution

The qualitative frames and annotations shown in the CMMT experiment gallery are
from **DAVIS 2017 (Densely Annotated VIdeo Segmentation)** and are used for
non-commercial research evaluation.

- Dataset website: <https://davischallenge.org/>
- Dataset license metadata: [Creative Commons Attribution-NonCommercial 4.0
  International](https://creativecommons.org/licenses/by-nc/4.0/)

Please cite the DAVIS benchmark works when using these results:

- F. Perazzi et al., *A Benchmark Dataset and Evaluation Methodology for Video
  Object Segmentation*, CVPR 2016.
- J. Pont-Tuset et al., *The 2017 DAVIS Challenge on Video Object Segmentation*,
  CVPR Workshops 2017.

The colored model overlays, scores, layout, and CMMT analysis are derived research
outputs of this project. They do not replace the official DAVIS distribution.
