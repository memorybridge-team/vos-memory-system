# test10 — Small → Base+ Affine 상태 전환 실험

SAM 2.1 Small에서 Base+로 모델을 전환할 때, 선형 변환의 가능성을 검토해본다. 
간단한 선형 구조 Wx+b 를 통하여 상대적으로 유사한 small 과 base+의 representation 차이가
단순한 선형(affine?) 변환으로 설명될 수 있는지 확인한다. 

선형 모델 학습 조건은 다음과 같다. 학습 조건 및 비교군은 최대한 non-linear translator의 
transfomer과 유사하게 설정하였다.

maskmem_features에 대해서는
```math
\hat{M}_{h,w} = M_{h,w}W_s + b_s
```
obj_ptr에 대해서는 
```math
\hat{p} = pW_p + b_p
```
로 각각 선형 변환을 수행한다


### Affine 모델 학습 조건

| 구분 | 항목 | 설정 |
|---|---|---|
| 모델 | 변환 방식 | Spatial memory와 object pointer에 각각 `Wx+b` 적용 |
| 모델 | Spatial 변환 | 위치마다 같은 64 → 64 선형층 사용 |
| 모델 | Pointer 변환 | 256 → 256 선형층 |
| 모델 | 파라미터 수 | 69,952개 |
| 데이터 | 학습 데이터 | LVOSv2 fit: 1,488 pair / 347영상 |
| 데이터 | 검증 데이터 | LVOSv2 development: 315 pair / 73영상 |
| 데이터 | 유효 memory record | 학습 23,808개 / 검증 5,040개 |
| 데이터 | 학습 목표 | 같은 영상·객체·시점의 Small 상태 → Base+ 상태 |
| 데이터 | 증강 | 없음 |
| 손실 | 구성 | 정규화된 spatial MSE + 정규화된 pointer MSE |

### 결론
1. Affine 변환은 효과가 크다 : Affine 학습에 사용하지 않은 MOSE testset에서 전체 후속 구간 J&F는 다음과 같다.

| 방법 | J&F |
| --- | --- |
| Direct Copy | 27.50 |
| Affine | **71.95** |
| 저장된 Base+ 상태 기준 | 73.22 |

Affine은 단순 복사보다 44.45점 높고, Base+ 상태 기준과의 차이는 1.27점입니다. 다른 데이터셋에서도 효과가 나타났다는 점이 현재 가장 강한 근거이다.

2. 전환 직후에는 잘 복구하지만 장기 추적 차이가 남는다

MOSE의 Affine 점수는 다음과 같다.

- +1프레임: 77.75
- +10프레임: 75.81
- 첫 10프레임 평균: 76.85
- 전체 후속 구간: 71.95

전환 직후부터 높은 성능을 보이므로, 수십 프레임이 지난 뒤에야 복구되는 형태는 아니다. 이후 점수가 낮아지지만 Base+ 상태 기준도 첫 10프레임 78.00 → 전체 구간 73.22로 내려간다. 따라서 하락 전체를 메모리 전송 오류나 누적 오차 탓으로 해석할 수는 없다.

3. LVOS 결과는 일반화 근거로 쓰기 어렵다

LVOS의 Affine 전체 구간 성능은 93.83~93.89점으로 높습니다. 그러나 해당 영상들은 Affine 학습 또는 체크포인트 선택에 사용됐습니다. 학습한 데이터에서의 복구 능력을 보여주며, 독립 테스트 성능을 입증하지는 않습니다.

4. 아직 입증하지 못한 주장

- Transformer보다 Affine이 좋다: Transformer 평가가 없고 학습 조건도 다릅니다.
- Base+ 전체 실행과 거의 같다: 비교 기준은 저장된 Base+ 상태에서 이어 추적한 결과입니다.
- Small에서 Base+로 전환하면 성능이 오른다: 현재 실행에는 Small-only 비교가 없습니다.
- 완전한 상태 복구: 출력의 정확한 일치나 모든 사례의 성공을 입증한 것은 아닙니다.

현재 연구 결과를 한 문장으로 쓰면:

“LVOS로 학습한 Affine 변환은 MOSE에서도 단순 상태 복사 대비 추적 성능을 크게 개선했으며, 평가 완료 사례의 전체 후속 구간 J&F는 저장된 Base+ 상태 기준보다 1.27점 낮았다.”
