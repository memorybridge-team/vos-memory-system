- [`cmmt-html/`](cmmt-html/README.md) — CMMT의 Small → Base+ 메모리 전달과 상태 조립 과정을 보여 주는 HTML 시각화 자료.

- [`test7/`](test7/README.md) — Base+의 메모리를 다른 Base+ 인스턴스에 복사해 추적 결과가 일치하는지 확인한 실험.

- [`test12/`](test12/README.md) — Base+의 연속 추론과 전체 프레임 재처리(Full Replay)의 출력 및 상태를 비교한 실험.
- [`test14/`](test14/README.md) — Small → Base+ 메모리 변환 모델의 구조를 검토하고 파인튜닝으로 추적 정확도를 개선한 실험.
- [`test15/`](test15/README.md) — Small → Base+ 전환 시 메모리 재개, 변환, 프롬프트 재시작의 정확도와 비용을 비교한 실험.
