# CMMT HTML 시각화

`vos-memory-translator-nonlinear`의 `docs`에 있는 HTML을 그대로 옮긴 자료입니다. 스타일과 스크립트는 각 파일 안에 들어 있습니다.

- `index.html`: Small → Base+ nonlinear memory handoff 작업 색인
- `architecture/cmmt-state-assembly-map.html`: CanonicalState를 Target SAM 2 상태로 조립하는 지도

`index.html`의 State Assembly Map 링크는 `architecture/cmmt-state-assembly-map.html`을 가리킵니다. 브라우저에서 `index.html`을 열면 됩니다.
